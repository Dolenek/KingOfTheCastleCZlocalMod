## About the project

**KingOfTheCastleCZlocalMod** is an unofficial Czech localization of **King of the Castle**. It translates local English text into Czech, from menus and the tutorial to stories, schemes and voting questions. The project includes translation dictionaries, build tools and an installer that can restore the original English files.

The interface and important recurring text have manually refined translations. The extensive stories were translated with a local translation model. The aim is readable Czech while preserving game conditions, variables and story logic.

> **The source repository and the installation package are two different forms of the project.** A repository clone contains translations and source code. Installation also requires the built files in `patched/` and a matching `manifest.json`.

## Translation coverage

| Area | What is included |
| :--- | :--- |
| 🎮 Interface | Menus, buttons, tutorial, rules and game messages |
| 👑 Kingdom | Regions, statistics, buildings, schemes and victory conditions |
| 📜 Stories | All 1,005 discovered Ink story scripts and 3 additional embedded scripts |
| 🗳️ Voting | Questions and choices generated by the local game |
| 🔤 Czech characters | A fallback font for Czech diacritics and translation of text when displayed |

| Processed data | Count |
| :--- | ---: |
| Discovered source strings | 45,224 |
| Translation dictionary entries | 46,085 |
| Total story scripts | 1,008 |
| Words in the source text | 612,271 |

Names and nicknames in the credits, URLs and Twitch commands are preserved. Internal identifiers, conditions and values used by game logic are not translated; some names are therefore localized only when displayed.

The separate `kotc.app` website, the Steam interface and newly downloaded messages are outside the scope of this mod. Voting questions generated by the translated game are passed on as part of the game data.

## Installing a built package

You need an **original Windows installation of the game from Steam** whose files match the checksums in the manifest. This beta was built for a local installation using Unity **2021.3.45f1**; the Unity version alone does not guarantee compatibility with another game build.

1. Close the game.
2. Place the `KingOfTheCastleCZlocalMod` folder directly beside `KingOfTheCastle.exe`.
3. Check that the package includes `patched/`, `manifest.json` and `translations.json`.
4. Run [Nainstalovat.cmd](Nainstalovat.cmd). The installer verifies the files, saves a backup and installs the Czech localization.
5. Start the game through Steam as usual.

```text
King of the Castle/
├── KingOfTheCastle.exe
├── KingOfTheCastle_Data/
└── KingOfTheCastleCZlocalMod/
    ├── Nainstalovat.cmd
    ├── Obnovit_anglictinu.cmd
    ├── translations.json
    ├── manifest.json
    ├── patched/
    └── backup/                ← backup created by the installer
```

Czech replaces the English text; there is no additional language to select in the game menu. The installer does not launch the game. Keep the folder name `KingOfTheCastleCZlocalMod`, as the interface translation library uses it.

### Restoring English and updating the game

Run [Obnovit_anglictinu.cmd](Obnovit_anglictinu.cmd). The original game files are restored from `backup/`, which remains available afterwards.

Restore English before updating the game. The installer refuses to overwrite files from another game version or files changed by another mod. Steam's file verification may overwrite the localization.

## Quality and validation

**Version 0.1.0 is the first beta.** The core interface, the complete tutorial, 187 recurring scheme objective descriptions, victory conditions and many important descriptions were manually refined. The stories have not yet received a full editorial review; they may contain inaccuracies, literal phrasing or incorrect inflections of inserted names and titles.

Automated checks verify the preservation of Ink instructions, references, game values, identifiers, Odin binary data and the structure of modified assemblies. All 1,008 scripts were successfully loaded using the Ink library shipped with the game. The final mod was validated through code and data comparisons; these checks do not confirm the appearance of every screen or behavior throughout a full playthrough. The fallback font may differ slightly from the original typeface.

When reporting an issue, include the original text, a suggested translation and where it appears in the game. A screenshot helps establish the context and available space.

## Translations and development

| File or folder | Purpose |
| :--- | :--- |
| [translations.json](translations.json) | Complete translation dictionary |
| [manual.json](manual.json) | Manually refined translations |
| [catalog.json](catalog.json) | Catalog of discovered source strings |
| [tools/](tools/) | Extraction, translation, building and validation |
| [tools/Runtime/](tools/Runtime/) | Interface translation at display time and Czech diacritics |
| [Install.ps1](Install.ps1) / [Restore.ps1](Restore.ps1) | Installation and restoration of original files |

Editing the dictionary alone does not change text already written into story bundles. Rebuild the mod after correcting a translation. Restore the original English files before building.

Building requires the original game installation, configured Python and .NET environments, the necessary dependencies, the translation model and generated inventories. The large `tools/field_inventory.json` is regenerated with `tools/pipeline.py extract`; [tools/finish.ps1](tools/finish.ps1) orchestrates building and validation. Complete automated setup of the development environment is not yet included. The model and development tools are not needed to play with a built package.

### What belongs in Git

The repository root is the `KingOfTheCastleCZlocalMod` folder. [.gitignore](.gitignore) keeps translations, source code, scripts and documentation. Backups, built game files, manifests, models, development environments, decompiled files, caches and diagnostic reports are excluded from Git. The installation package is prepared separately.

## Tools used

- Translation model: [Helsinki-NLP/opus-mt-tc-big-en-ces_slk](https://huggingface.co/Helsinki-NLP/opus-mt-tc-big-en-ces_slk), licensed under CC BY 4.0. Its output was adapted to preserve variables and formatting and supplemented with manual translations.
- Game data: [UnityPy](https://github.com/K0lb3/UnityPy).
- Translation: [CTranslate2](https://github.com/OpenNMT/CTranslate2).
- Assembly patching: [Mono.Cecil](https://github.com/jbevain/cecil).
